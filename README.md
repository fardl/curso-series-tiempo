## Contenido del curso

El curso se organiza en cuatro bloques:

1. **Fundamentos univariados** (semanas 1–2): estacionariedad, ACF/PACF.
2. **Modelos ARIMA** (semanas 3–6): Box-Jenkins, raíz unitaria, pronóstico.
3. **Modelos multivariados** (semanas 7–11): VAR, SVAR, cointegración, VECM.
4. **Volatilidad y cierre** (semanas 12–14): GARCH, presentaciones.
